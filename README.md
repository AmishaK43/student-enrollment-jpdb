# Student Enrollment Form Using JsonPowerDB

## 1. Title of the Project

**Student Enrollment Form Using JsonPowerDB**

## 2. Description

The Student Enrollment Form is a web-based application developed using HTML, CSS, JavaScript, jQuery and JsonPowerDB.

The project is designed to store and manage student enrollment details in the `STUDENT-TABLE` relation of the `SCHOOL-DB` database.

The Roll Number is used as the primary key to uniquely identify each student.

### Input Fields
- Roll Number (Primary Key)
- Full Name
- Class
- Birth Date
- Address
- Enrollment Date

## 3. Benefits of Using JsonPowerDB

- Simple and easy to use.
- Schema-free database.
- Supports JSON-based data storage.
- Provides REST API support.
- Reduces development time.
- Offers high performance.
- Supports multiple database operations.

## 4. Scope of Functionalities

- Enter student enrollment details.
- Search student records using Roll Number.
- Save new student records.
- Update existing student records.
- Validate input fields.
- Reset the form.

## 5. Technologies Used

- HTML
- CSS
- JavaScript
- jQuery
- JsonPowerDB

## 6. Database Details

| Property | Value |
|---|---|
| Database Name | SCHOOL-DB |
| Relation Name | STUDENT-TABLE |
| Primary Key | Roll-No |

## 7. Examples of Use
